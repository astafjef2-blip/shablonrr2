# Формат JSON-спецификации

Модель описывает презентацию в JSON, а `scripts/build_from_spec.py` превращает его в `.pptx`. Модели не нужно считать координаты: каждый `type` — готовый макет с продуманной сеткой.

```json
{
  "meta":   {"title": "Название файла в свойствах", "author": "Управление Росреестра по …"},
  "output": "out/presentation.pptx",
  "slides": [
    {"type": "title", "title": "…", "kicker": "…", "author": "…", "role": "…", "notes": "…"},
    {"type": "cards", "title": "…", "cards": [ … ], "notes": "…"},
    {"type": "final"}
  ]
}
```

## Общие поля слайда

| Поле | Тип | Описание |
|---|---|---|
| `type` | строка | Макет: `title`, `section`, `final`, `kpi_table`, `kpi_chart`, `metric_bars`, `cards`, `numbered`, `checklist`, `flow`, `statement`, `cards_image`, `table`, `chart`, `timeline`, `bullets` |
| `title` | строка | Заголовок (≤ 60 символов; при переполнении кегль уменьшается автоматически) |
| `notes` | строка | Заметки докладчика: полный текст доклада к этому слайду. Абзацы разделяются `\n` |

Поля, которых нет у макета, игнорируются с предупреждением; если не задано обязательное поле, сборка останавливается с ошибкой.

## Разметка текста

Работает в любом текстовом поле:

| Разметка | Результат |
|---|---|
| `**текст**` | акцент: синий полужирный (на синем фоне — белый полужирный) |
| `!!текст!!` | предупреждение: оранжевый полужирный |

Пример: `"**Источники ВРИ:** градостроительный регламент…"`, `"!!Запрещено!! строительство…"`.

## Цвета

Где поле допускает цвет (`color` в прогресс-барах, `colors` в диаграммах): `blue`, `blue2`, `navy`, `green`, `teal`, `orange`, `pale`, `light`, `lightgreen`, `text`, `gray`, `white` — или HEX `"#008CFF"`.

## Иконки и иллюстрации

* `icon` — id из `docs/icons.md`, например `"documents_scroll_seal"`. Белый вариант для синих плашек подставляется автоматически. Если id указан с опечаткой, сборщик подберёт ближайший и выдаст предупреждение.
* `illustration` — `people_house`, `surveyor`, `analyst_chart`, `specialist_map` или путь к PNG.

## Составные объекты

### KPI
```json
{"value": "635 508", "label": "заявлений поступило всего", "delta": "▲ +53,2%  (+220 664)",
 "icon": "documents_paper_stack", "dark": false}
```
`delta` окрашивается автоматически: начинается с `−`, `-` или `▼` — оранжевым, иначе зелёным; можно задать явно через `delta_color`. `dark: true` — карточка с фирменным градиентом.

### Таблица
```json
{"columns": ["Показатель", "2025", "2026", "Изменение", "Темп, %"],
 "rows": [["Кадастровый учет", "55 333", "42 825", "−12 508", "−22,6"]],
 "col_widths": [190, 100, 100, 105, 95],
 "bold_rows": [3, 4],
 "highlight_rows": [3, 4],
 "delta_cols": [3, 4],
 "accent_cols": [2]}
```
Индексы считаются с 0 и относятся к `rows`, без строки заголовка. `delta_cols` красятся по знаку, `accent_cols` выделяются синим полужирным (обычно текущий период). Числа передавайте строками, уже отформатированными.

### Диаграмма
```json
{"type": "column",
 "categories": ["На основании договора", "В силу закона"],
 "series": [{"name": "9 мес. 2025", "values": [7522, 21241]},
            {"name": "9 мес. 2026", "values": [13956, 20468], "color": "blue"}],
 "number_format": "# ##0", "legend": true, "labels": true, "max": 32000, "colors": ["pale", "blue"]}
```
`type`: `column`, `bar`, `stacked_column`, `stacked_bar`, `line`, `pie`, `doughnut`. Для `pie` / `doughnut` — один ряд; `percent: false` показывает значения вместо процентов. Диаграммы создаются как настоящие объекты PowerPoint, и их данные можно редактировать.

### Прогресс-бары
```json
{"title": "Доля электронных заявлений",
 "items": [{"label": "2025", "value": 64.7, "color": "pale"},
           {"label": "2026", "value": 81.7, "color": "green", "text": "81,7%"}],
 "badge": {"value": "+17", "caption": "п.п. за год"}}
```
`max` у элемента задаёт шкалу (по умолчанию 100); `text` подменяет подпись внутри полосы.

### Карточка
```json
{"icon": "maps_map_flag", "title": "Без межевания — без сделок", "text": "…", "highlight": true}
```

### Выноска (callout)
```json
{"icon": "objects_clock_fast", "text": "**Электронные обращения — не более 1 дня.** …", "style": "filled"}
```
`style`: `filled` (градиент, белый текст), `outline` (белая с синей рамкой), `light` (светло-голубая).

Поля каждого макета, лимиты и примеры — в [layouts.md](layouts.md).
